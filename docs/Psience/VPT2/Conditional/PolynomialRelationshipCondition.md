## <a id="Psience.VPT2.Conditional.PolynomialRelationshipCondition">PolynomialRelationshipCondition</a> 

<div class="docs-source-link" markdown="1">
[[source](https://github.com/McCoyGroup/Psience/blob/master/Psience/VPT2/Conditional.py#L225)/
[edit](https://github.com/McCoyGroup/Psience/edit/master/Psience/VPT2/Conditional.py#L225?message=Update%20Docs)]
</div>

An arbitrary McUtils endpoint function compared with zero.

The arguments are the selected source occupations followed by the target
occupations. Use ``symmetrized`` for a directional relation in a unitary
transformation; an invariant equality is symmetric by construction.
